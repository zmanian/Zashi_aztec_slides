# Zashi - End User Zcash Wallet Presentation

A comprehensive reveal.js slide deck covering Zashi wallet usage and Zcash privacy features.

## 📋 Contents

### 1. Getting Started
- Understanding T-addresses vs U-addresses
- When to use transparent addresses
- What are viewing keys and how to use them

### 2. Using Zashi
- Converting from USDC/BTC to ZEC
- Paying recipients who don't accept ZEC
- Practical swap service recommendations

### 3. Advanced Topics
- RPC server selection
- Latency considerations
- IP privacy with Tor

## 🚀 How to View

### Option 1: Open Locally
Simply open `index.html` in your web browser:
```bash
open index.html
# or
firefox index.html
# or
google-chrome index.html
```

### Option 2: Serve with Local Server
For best results, serve with a local HTTP server:

**Using Python:**
```bash
# Python 3
python -m http.server 8000

# Then visit: http://localhost:8000
```

**Using Node.js:**
```bash
npx http-server
```

**Using PHP:**
```bash
php -S localhost:8000
```

## 🎮 Controls

- **Arrow Keys** / **Space**: Navigate slides

3. Add/remove slides by editing `<section>` elements
4. Change theme by modifying the theme CSS link
