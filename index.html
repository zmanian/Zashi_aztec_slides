1. Getting Started

Address Types: T vs U

T-Addresses (Transparent)

Start with "t1..."

  • ❌ No privacy
  • ✅ Visible on blockchain
  • ✅ Works with exchanges
  • ✅ Lower fees

U-Addresses (Unified)

Start with "u1..."

  • ✅ Full privacy
  • ✅ Shielded transactions
  • ✅ Hides amounts & sender
  • ✅ Recommended!

When to Use T-Addresses

✅ Use T-Addresses For:

  • 🏦 Exchange deposits/withdrawals
  • 📊 Receiving from services that don't support shielded
  • 🔄 Temporary holding before shielding
  • 💸 When sender only supports transparent

⚠️ Always shield (move to U-address) as soon as possible for privacy!

🔑 What are Viewing Keys?

  • 👁️ View-only access to your shielded transactions
  • 🔒 Can see balances & history, but cannot spend
  • 📊 Perfect for accountants, auditors, or tax compliance
  • 🛡️ Share transaction data without risking funds

Use case: Give your accountant a viewing key to see transactions for tax purposes without giving them spending power

Types of Viewing Keys

Full Viewing Key (FVK)

  • See all incoming & outgoing
  • View full transaction history
  • Complete transparency

Incoming Viewing Key (IVK)

  • Only see received funds
  • Outgoing hidden
  • More selective privacy

2. Using Zashi

From USDC/BTC to ZEC

Option 1: Centralized Exchanges

  1. Send USDC/BTC to exchange (Coinbase, Kraken, Binance)
  2. Trade for ZEC
  3. Withdraw to your Zashi t-address
  4. Shield to u-address in Zashi

Option 2: DEX/Swaps

  1. Use SideShift.ai, ChangeNow, or similar
  2. Swap BTC/USDC directly to ZEC
  3. Receive to Zashi u-address

🔄 Swap Services

Popular Non-KYC Options:

  • 🦊 SideShift.ai - No account needed
  • ⚡ ChangeNow - Fast swaps
  • 🔐 StealthEX - Privacy-focused
  • 🌐 Exolix - Multiple pairs

⚠️ Always verify you're on the official site - phishing is common!

Paying Without ZEC

When recipient wants BTC/USDC/fiat

Step 1: Convert ZEC

  • Unshield ZEC to t-address (if needed)
  • Send to exchange or swap service
  • Convert to BTC, USDC, or other crypto

Step 2: Send to Recipient

  • Withdraw to their address
  • Or use payment processor (BitPay, etc.)

💡 Pro tip: Use instant swap services for quick conversions

Payment Workflow Example

Scenario: Pay $100 to someone who wants USDC

  1. Check ZEC price (~$28 per ZEC)
  2. Send ~3.6 ZEC from Zashi to SideShift
  3. Specify recipient's USDC address
  4. SideShift converts & sends ~100 USDC
  5. Done! ✅

3. Advanced Topics

🌐 What are RPCs?

Remote Procedure Call servers

  • 🔗 Connect your wallet to the Zcash blockchain
  • 📡 Relay transactions and fetch data
  • 🏛️ Can be run by you or trusted third parties

Your RPC choice affects speed, privacy, and reliability

⚡ RPC Selection: Latency

Low Latency Matters For:

  • Fast transaction broadcast
  • Quick balance updates
  • Smooth app experience
  • Real-time sync

How to Choose:

  • 🌍 Geographic proximity
  • ⚡ Ping/response time
  • 📊 Uptime/reliability
  • 🔄 Load balancing

Zashi usually auto-selects good defaults

Testing RPC Latency

# Test RPC response time

curl -X POST https://rpc.example.com \

-H "Content-Type: application/json" \

-d '{"jsonrpc":"2.0","method":"getinfo","id":1}' \

-w "Time: %{time_total}s\n"

Aim for <500ms for best experience

🕵️ IP Privacy: Why It Matters

  • 🔍 RPC servers can see your IP address
  • 📍 IP can reveal your location
  • 🔗 Could correlate IP with transaction patterns
  • ⚠️ Even with shielded transactions, metadata leaks exist

Solution: Use Tor

🧅 Using Tor with Zashi

Benefits:

  • 🌐 Hides your real IP from RPC servers
  • 🔒 Routes through encrypted relays
  • 🎭 Adds anonymity layer
  • 🛡️ Protects against network surveillance

Trade-offs:

  • 🐌 Slower connection (higher latency)
  • ⚠️ Requires Tor setup/Orbot on mobile
  • 🔄 Some RPCs may block Tor exits

Setting Up Tor

On Android:

  1. Install Orbot from F-Droid or Play Store
  2. Start Orbot and enable VPN mode
  3. Configure Zashi to use Tor proxy (if supported)

On iOS:

  1. Install Onion Browser or similar
  2. Use VPN-based Tor apps
  3. Check Zashi settings for proxy support

Note: Check Zashi documentation for current Tor support status

🎯 RPC Best Practices

Recommendations:

  • 🏠 Run your own node (best privacy & control)
  • 🔐 Use trusted, well-known RPC providers
  • 🧅 Enable Tor for maximum privacy
  • 🔄 Rotate between multiple RPCs
  • 📊 Monitor for downtime/issues
  • ⚡ Balance speed vs. privacy based on needs
